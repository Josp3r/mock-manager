# System proxy switch

User requests a system-proxy toggle inside the existing macOS desktop app, so browser mocking does not depend on SwitchyOmega. This authorizes implementing and packaging the feature. It does not require automatically enabling the user's live network settings during development.

Use the existing Connection Settings, with a separate “系统代理” switch and real status. Enable HTTP and HTTPS proxies on enabled, proxy-capable services in the current network location, using the running Whistle address. Temporarily disable PAC, automatic discovery and SOCKS selection so they cannot override the HTTP proxy; preserve bypass lists and all original configuration. Save a durable, private backup before any mutation. Turning off restores application-owned changes, even if Whistle has stopped or the application restarted. External edits must be preserved. Closing the window keeps the setting, consistent with Whistle continuing to run; the UI explains this. HTTPS certificates remain independently configured.

Implementation choice: a small bundled Swift helper using SystemConfiguration. It reads full Proxies dictionaries and protocol enabled flags; mutations use the native authorization UI and a locked read/compare/set/commit/apply transaction. It never reads or edits Keychain passwords. Because endpoint changes with authentication metadata are not verified safe, refuse takeover of HTTP/HTTPS configurations containing authentication metadata. The renderer cannot choose commands, network services, paths or proxy targets. Main process obtains the target from the verified Whistle status. Alternative w2 proxy/set-global-proxy lacks restoration and clears bypass configuration. networksetup cannot faithfully recover authenticated configuration and has no transaction spanning compare/write.

The persistent journal records service IDs and before/installed snapshots. Restoration requires all still-existing managed service configurations and protocol flags to equal the complete installed snapshot (or the complete original snapshot after an interrupted restore). Any external edits cause a visible conflict without writes. A separate explicit “保留当前设置” confirmation archives the backup and ends management without touching system settings. Readback verifies success; cancelled authorization and interrupted writes retain recoverability without reporting false success. Missing services are reported and not silently discarded. Status is configuration status, not a guarantee that all applications follow system proxy settings.

Deliver macOS arm64 v0.1.1, source history, instructions and tests. No cloud service, privileged daemon, automatic certificate installation, or unsolicited live proxy changes.
