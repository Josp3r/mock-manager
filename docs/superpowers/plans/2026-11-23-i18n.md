# Mock Manager Internationalization Implementation Plan

> **For agentic workers:** Follow the scoped tasks below, preserving shared interfaces. Root integrates and reviews the combined changes.

**Goal:** Ship Simplified Chinese and English, then push the verified source to Josp3r/mock-manager.

**Architecture:** Shared bilingual translation and locale resolver; independent persisted language preferences owned by main; renderer subscription loads before rendering. Translate existing UI/services in place.

**Tech Stack:** Existing Electron, React, TypeScript, Vite and Vitest. No new runtime dependency.

**Spec:** ../specs/2026-11-23-i18n-design.md

## Global Constraints
- Languages: zh-CN and en; preference: system, zh-CN, en.
- No mutation of user-authored content, project schema, rule IDs, data root or proxy/quit semantics.
- Tests use isolated profiles and proxy fixtures; no real OS proxy/trust writes.
- User authorized GitHub code push; preserve remote work, never force push.

## Review Focus
- Unknown/malformed preferences and non-Chinese system fallback.
- Live switching while a draft exists, and persistence through a new window/restart.
- Native menus/error output matching renderer; no stale language captured at module load.
- Long English controls at 1080px; full accessible labels remain.
- Source publication excludes personal app data, private certificates and generated runtime profiles.
